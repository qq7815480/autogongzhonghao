适用：撰写“Claude 破解黎曼猜想 / 刷新黎曼研究纪录 / AI 做开放数学研究”相关新闻、评论或辟谣文章。

检索基准：2026-08-11。后续使用时先检查是否已有勘误、独立审稿意见或正式发表版本。

## 一句话事实边界

Claude 没有证明黎曼猜想。Anthropic 公布的一篇 Claude 署名论文，把“能够无条件保证位于临界线上的非平凡零点比例下界”从约 41.6% 提高到约 67.25%。截至公告发布时，论文有专家短时检查和 Lean 形式化，但尚未走完传统期刊同行评审。

## 可直接采用的硬事实

- 官方公告日期：2026-08-10。
- 具体模型只写作“未发布研究版本的 Claude”，检查点和公开端点均未披露。
- 两轮 Claude Code 会话共约 3100 万 output tokens。
- 第一轮尝试约 650 个想法，全部失败。
- 第二轮约一天半，协调约 60 个 Claude 子代理。
- 共执行约 2400 个 shell 命令，编写数百个 Python 脚本，完成数千次数值检查。
- 代理分工：2 个发展关键数学想法，13 个提供支持想法，30 个探索失败，13 个验证，2 个协助写论文初稿。
- 后续检索下载了 54 篇 arXiv 论文，用于检查相关工作和优先权。
- Anthropic 数学家 Levent Alpöge、Ralph Furman 检查论证；Brian Conrey、Daniel Goldston 在短时间内看过论文；Eric Easley 协助 Lean 形式化。
- 论文主要结论：临界线上的不同零点和单零点比例下界至少为 2/3；优化窗口后约为 0.67250；全部不同零点比例约为 0.83625。
- 旧的已发表无条件临界线比例纪录为超过 5/12，即约 41.666%，来自 2020 年 Pratt 等人的论文。
- Anthropic 明确表示不认为当前技术能导向黎曼猜想的完整证明。

## Lean 证据应如何表述

仓库 README 声明：

- 覆盖论文 Theorems A–E。
- 主体形式化无 `sorry` 占位。
- 顶层定理无额外数学假设，只出现 Lean/Mathlib 标准逻辑公理 `propext`、`Classical.choice`、`Quot.sound`。
- 提供 comparator 配置与构建、审计步骤。

写作时不要说“Lean 已经让争议结束”。准确说法是：Lean 检查形式系统内的推导，外部专家仍需确认形式化命题、定义和自然语言数学主张完全对应。形式验证和语义审查互补。

## 五条必写澄清

1. 不得写“Claude 破解 / 证明了黎曼猜想”。
2. 不得写“黎曼猜想完成了 67.25%”。
3. 剩余 32.75% 是这一定理未分类的零点，不代表已证明它们位于临界线外。
4. 这是渐近意义上的比例下界，不是逐一定位零点。
5. 即使密度意义上达到 100%，也未必自动证明“每一个零点都在线上”；仍可能留下密度为零的异常集合。

## 可信度分层

可确认：官方论文、Lean 仓库、旧纪录论文、工作流统计均已公开。

强支持但非终局：Anthropic 内部数学家验证，Conrey 和 Goldston 短时检查，Lean 形式化无占位。

仍待确认：更广泛独立社区审查、期刊同行评审、正式出版状态、后续勘误。

不可复现部分：发现所用的具体模型检查点、完整 3100 万 token 运行和未公开隐藏推理。

建议用“论文给出”“Anthropic 公布”“若后续独立审查确认”区分不同状态。

## 真人讨论分组

- 兴奋派：多年缓慢推进的下界一次提高约 25.6 个百分点，意义远超普通跑分。
- 工作流派：这不是单次聊天，而是把人类可能耗时数月或数年的多路线探索压缩到几十小时。
- 冷水派：要求可重复、可复现、稳定；未公开模型使完整发现过程无法外部重跑。
- 出版规范派：讨论 AI 署名、arXiv 作者政策、审稿人和作者责任如何划分。
- 叙事质疑派：警惕把“继续”“相信自己”拟人化；更准确的解释是人类给系统继续搜索和消耗推理预算的控制信号。

Ralph Furman 在 HN 的公开回应可作为重要真人材料：他将自己的角色描述为高度投入的审稿人，认为按数学界标准不适合署名为论文作者，但愿意为数学正确性承担责任；论文仍会继续打磨并准备正式发表。

## 推荐文章主线

优先主线：黎曼猜想没被破解，但 AI 已从“做有标准答案的数学题”进入“参与开放研究”的更深区域。

文章重点放在三件事：

1. 67.25% 的准确数学含义和边界。
2. 3100 万 token、60 个代理、生成与验证分离的研究组织方式。
3. Lean、专家审查、传统同行评审分别解决什么问题。

不要把主线写成“不会数学的人靠一句提示词创造奇迹”。准确研究单位是：人类定题与授权资源、AI 大规模探索、工具做数值检查、形式系统核验推导、领域专家检查语义和优先权。
