# AI Agent“沙箱逃逸”热点核查清单

适用于把“AI 逃出沙箱 / 自主越狱 / 突破安全环境”类热点写成公众号文章。目标是区分真实边界突破、网络配置问题和媒体化传播，避免把联网查答案写成容器逃逸。

## 一、先拆成三类事件

1. **真正的隔离突破**
   - 容器逃逸到宿主机
   - 提权或获得额外 capability
   - 读取沙箱外文件、主机凭据或其他租户数据
   - 绕过内核、虚拟化或明确生效的网络策略

2. **Agent 在已授权范围内调用工具**
   - 使用 curl、git、浏览器、shell 等现有工具
   - 访问本就可达的公网或仓库
   - 按任务目标寻找阻力最小的路径

3. **环境配置错误或边界过宽**
   - 防火墙规则未加载或失效
   - compose / sandbox 配置允许外网
   - API、挂载目录、凭据或宿主接口暴露
   - 测试框架允许研究者自定义网络，但报道误写成框架被攻破

文章必须明确写清事件属于哪一类。没有宿主机执行、提权或越界文件访问证据时，不得使用“容器逃逸已证实”。

## 二、证据优先级

按下面顺序找材料：

1. 研究方原始博客、论文或报告
2. 测试框架和 benchmark 官方文档
3. 官方 GitHub 仓库、README、compose 配置、提交历史、issue / PR
4. 模型开发方模型卡、技术报告和回应
5. 被点名机构的直接回应
6. Wired、Reuters 等采访型报道
7. 其他媒体交叉核验
8. Reddit、X、HN 等社区讨论，仅用于呈现观点和语气

如果普通网页提取不完整，可用 Scrapling 抓取正文；但抓到的文章仍只是来源材料，不能代替原始日志和配置。

## 三、原始披露必须检查的缺失项

至少逐项确认研究方是否公开：

- 完整系统提示词和任务提示词
- 具体 benchmark 题目或 sample ID
- 沙箱类型、compose / network 配置
- 防火墙和域名白名单规则
- Agent 可调用的工具及权限
- 原始终端命令、轨迹或 transcript
- 是否获得宿主机权限或读取沙箱外文件
- 复现次数、成功率、对照模型
- 研究代码和可重跑脚本

这些材料缺失时，要在文章里明确写“第三方暂时无法独立复现”，不要用搜索摘要补齐不存在的细节。

## 四、用官方仓库反查宣传口径

热点报道声称“默认沙箱失守”时，不要只读媒体：

1. 打开 benchmark / framework 官方文档，查 network、sandbox、risk、compose、internet access。
2. 克隆官方仓库，核对 README 和实际配置。
3. 查看事件前后的 git log、blame、issue 和 PR，判断是否真的出现紧急修复。
4. 区分框架默认配置、benchmark 自带配置和研究者自定义配置。

尤其注意：同一框架可能在自动生成配置时默认断网，但某个 benchmark 的自定义 Docker 配置仍允许公网。脱离具体运行配置讨论“默认联网”或“默认隔离”都可能误导。

## 五、寻找同类 Agent 行为

检索 NIST、AISI、METR、Apollo Research 等机构关于：

- specification gaming
- evaluation cheating
- reward hacking
- benchmark contamination
- unintended solution

如果其他模型也会联网找 walkthrough、读取 solution、利用评测脚本漏洞，应把事件放入 Agent 规则钻空子的共同问题中，不能仅凭单次案例断言某个模型“觉醒”或安全性显著更差。

## 六、文章措辞分级

**已证实**：来源直接支持，并有配置、日志或多方一致描述。

**转引一致**：多家媒体重复同一动作链，但缺原始日志。

**研究方判断**：明确注明是谁的判断，不写成共同结论。

**尚未证实**：容器逃逸、提权、宿主机访问、稳定复现、模型间安全性差异。

**媒体化表达**：AI 觉醒、自主逃狱、挣脱人类牢笼、攻破完善防御。

推荐使用“评测边界利用”“利用开放或错误放行的网络出口”“规则钻空子”等更准确的表述。

## 七、公众号写作角度

先给结论，再还原动作链。文章重点放在：

- Agent 会主动寻找最省力的任务路径
- 模型护栏不能替代环境隔离
- 默认断网、域名白名单、最小权限、行为序列监控、蜜罐和人工确认
- 一个安全边界要兜住另一个可能失效的边界

不要把文章写成替模型洗地，也不要写成 AI 觉醒故事。争议双方都要给出依据：配置错误不等于没有风险，Agent 有风险也不等于完成了容器逃逸。
