# 公众号生成图片质量 gate

适用于正文信息图和封面。生图接口返回成功只代表拿到了文件，不代表图片可发布。

## 正文图逐张检查

每张生成图都必须调用视觉检查，要求模型：

1. 逐字抄出所有可见文字。
2. 检查错别字、异体字、繁简混用、乱码和英文大小写。
3. 检查箭头方向、流程顺序、左右对比关系是否与正文一致。
4. 检查图片是否自行添加了 prompt 未指定的口号、数据或结论。
5. 检查四周裁切和手机端小字可读性。
6. 明确给出“可发布”或具体硬伤。

发现硬伤时，先修改 prompt 文件，再重新生成；禁止只在正文里解释图片错误。重做后必须再次视觉检查。

## Prompt 防漂移写法

对事实型信息图，在 prompt 末尾列出允许出现的全部文字，并加：

“画面中只能出现以下文字……禁止自行添加任何其他口号、说明、数字或结论。所有中文必须使用规范简体字，逐字准确，禁止异体字和繁体字。”

对安全、医学、金融等敏感结论，避免让模型自行补充绝对化口号。推荐使用“可能”“公开材料尚未证明”“现有证据能够确认”等有边界的表述。

## 数学、科研与数据图额外 gate

事实型科研图必须把“文字正确”和“图形编码正确”分开检查：

1. **图形不能和数字打架**：柱高、比例条分界、饼图面积、时间轴位置必须与标注值一致。模型难以稳定画精确比例时，改用等尺寸数字卡片和箭头，不要继续赌一次重绘。
2. **上下界方向必须成对正确**：`至少 67.25%` 的互补部分应写 `至多 32.75%`；“尚未分类”不能画成“已在线外”或用红点暗示已经发现反例。
3. **坐标和数学对象必须准确**：例如虚轴 `Re(s)=0` 与临界线 `Re(s)=1/2` 不能重合；厄米矩阵是关于主对角线共轭对称，不能写成上下/左右镜像对称。
4. **不要让装饰公式制造硬伤**：如果公式、Lean 代码或伪代码不是文章论证必需内容，prompt 中明确禁止可读公式和代码，改用文件、盾牌、放大镜、检查表等概念图标。
5. **概览不能伪装成证明**：复杂证明流程图底部标“方法概览，不是完整证明”，并要求视觉检查只核对内部表达；结论数值另由论文与研究资料核验。
6. **多层验证要保持口径一致**：三栏就不要写“两道关”；区分形式推导检查、人工语义检查和传统同行评审，未完成的评审不能画成已通过。

发现这类硬伤时，删除易错的定量图形/装饰公式并重写 prompt，比在原图上补解释更可靠。

## 生图模型反复画错拓扑时的降复杂度策略

如果同一张架构图连续两次以上把 fallback 起点、返回箭头、工具连接或闭合分组画错，不要继续堆叠更长的箭头指令。按以下顺序降级信息表达：

1. 把多条双向箭头改成单向通道，减少方向数量。
2. 如果仍画错，把“调用流程图”改成“职责分层图”或“能力分组图”，只保留文章需要表达的职责边界，不再暗示调用拓扑。
3. Prompt 明确声明“这不是流程图”，并禁止箭头、连线、总线、虚线；如果验收要求绝对无箭头，还要禁止图标内部的路牌箭头。
4. 视觉复检时区分流程连线与装饰图标，但最终按 prompt 的字面约束验收。

目标是准确传达文章观点，不是逼生图模型复现复杂工程拓扑。连续失败后主动降低视觉复杂度，比无限重绘更可靠。

## 数据实验图的口径策略

- 论文实验数字必须用同一个大括号、边框或标题明确绑定到“同一组特定实验”，避免三个数字被读成跨场景通用结论。
- 数字卡附近应注明影响条件，例如路由器、模型组合、阈值、评测集与当时价格，并写清“不代表所有任务”。
- 生图模型不适合绘制无来源、无坐标和无标签的装饰柱状图；此类图会伪装成可核验数据，必须禁止。
- 如果完整来源、表号和计算口径无法在手机图中清楚呈现，把图片定位为“概念提醒图”，详细来源和实验条件放在正文，不要让图片冒充论文复现。

## 原始 SVG 素材转换

原始资料提供 SVG 时，优先用 macOS `sips` 直接转换：

`sips -s format png input.svg --out output.png`

不要优先用 Quick Look 缩略图导出。`qlmanage -t` 生成的是缩略图画布，可能出现正方形白边、内容放大或边缘裁切，不等于 SVG 的完整渲染。

转换后必须用视觉工具确认：画面完整、无白边、关键节点和文字未被裁掉。原图只做格式转换和必要裁切，不改写其信息内容。

## 封面裁切 gate

1. 先检查 16:9 原图标题是否准确、核心内容是否位于中央安全区。
2. 裁成 1536×653 后再次视觉检查。
3. 必查：标题、主体、问题符号、主要连线、关键容器边界是否完整。
4. 如果两种裁切方案存在取舍，标题完整优先于装饰性底边完整；但关键主体被明显切断时应回到 prompt 重生成，而不是无限调整 crop offset。
5. 不要只凭像素尺寸判断成功。

## 发布前最终断言

- 所有正文图均有明确“可发布”检查结论。
- 原图和生成图均使用绝对路径插入 `article.md`。
- 正文图已压缩到适合微信上传的尺寸和体积，保留未压缩源文件。
- 封面为 2.35:1，且裁切后视觉复检通过。
- 发布日志必须显示正文图片成功上传；不能只有封面上传成功。
